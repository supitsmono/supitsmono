## ⭐ Featured: [Earnr](https://earnr.org) — live in production

A subscription SaaS for high-ticket closers to track their clients, closed deals and the commission they've earned and are still owed.

- **Multi-tenant by design.** Every row is scoped to the user and enforced at the query level.
- **Money handled carefully.** Amounts are stored excl. VAT; paid totals and deal status (pending / partial / paid / overdue) are *derived* from payment records, never stored.
- **Payment-plan editor.** Instalments, mark paid/unpaid, overdue detection, KPI dashboard with charts per client.
- **Subscriptions** through Clerk Billing, with a premium gate and beta-access flags.

`Next.js 16` `TypeScript` `Turborepo` `Postgres (Neon)` `Drizzle ORM` `Clerk` `shadcn/ui` `Tailwind v4` `Recharts` `Vercel`

*(Source is private because it's a commercial product. Happy to walk through it on a call.)*
